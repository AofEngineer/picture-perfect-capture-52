# คู่มือสาธิต AUTODRIVE DMS

เปิด http://127.0.0.1:3000/ ใช้ธีมและส่วนประกอบ Lovable เดิม ข้อมูลทั้งหมดเป็นข้อมูลสมมติ บันทึกในเบราว์เซอร์ของเครื่องนี้

## เส้นทางขายรถ

1. เลือกบทบาท Sales แล้วไป Stock → Sales Stock Check กรอง Bonus และรถพร้อมขาย เปิดข้อมูลรถ แล้วสร้าง Booking เลือกลูกค้าในสาขาและวันส่งมอบ
2. ใน Booking → Customer & Documents ใช้เอกสารตัวอย่าง ตรวจ/แก้ผล OCR และยืนยัน
3. ตรวจ AMLO จำลอง หากขึ้น Error ให้ผู้ดูแลไป Integrations → AMLO → Retry แล้วกลับมาตรวจอีกครั้ง หากผลเป็น Review ต้องตรวจสอบเพิ่มเติมก่อนเดินขั้นตอนต่อ
4. ใน Contracts & Delivery ส่งสัญญาลงนาม วาดและยืนยันลายเซ็นเรียงตามฝ่าย
5. ใน Payment & Loyalty ใช้ Point ที่ไม่เกินยอดคงเหลือ/เพดาน จากนั้นบันทึกรับเงินให้ครบ หาก Loyalty ขัดข้อง ยอด Point จะยังไม่ลด ผู้ดูแล Retry ด้วย Reference เดิมใน Integrations
6. สลับเป็น Service Officer สร้าง/เปิด Service Order ของรถ ตรวจ Checklist จนครบและยืนยันตรวจรับ งาน Dashboard จะเสร็จตาม
7. สลับเป็น Stock Officer ไป Red Plate Management เลือกป้ายพร้อมใช้และจับคู่กับ Booking ในสาขาเดียวกัน
8. กลับ Booking ออกใบส่งมอบจาก Preview แล้ว Print หรือ Save as PDF เดิน Workflow ผ่านแต่ละขั้น ผู้จัดการอนุมัติปิดการขาย รถจะเปลี่ยนเป็นขายแล้ว พร้อม Commission และ Earn Point
9. ใน Sales → Commission ส่งเบิก ผู้จัดการตรวจผ่าน ฝ่ายการเงินอนุมัติและบันทึกจ่าย มีประวัติและใบเบิกให้พิมพ์

System Administrator สามารถดำเนินการข้ามบทบาทเพื่อสาธิตต่อเนื่องได้ แต่การทดสอบสิทธิ์ควรสลับแต่ละบทบาทจริง

## เส้นทางคืนเงิน

เปิด Booking อีกกรณี → Refund เลือกคืนเต็ม/หักบางส่วน/ไม่คืน/คืน Point/ส่งสาขาอื่นรับผิดชอบ ใส่เหตุผลและส่งคำขอ ผู้จัดการอนุมัติ ฝ่ายการเงินตรวจและบันทึกช่องทาง/หลักฐานก่อนจ่าย ระบบคืน Point ครั้งเดียวแล้วรอผู้มีสิทธิ์อนุมัติปล่อยรถ รถที่ยังมีงานเตรียมจะไม่กลายเป็นรถพร้อมขายทันที

## งานสต๊อกและป้ายแดง

- Stock Operations รับรถเข้า ตรวจ VIN และ Checklist ขอโอนรถ ผู้จัดการอนุมัติ ต้นทางส่งรถ ปลายทางตรวจรับจึงเปลี่ยนสาขา ยกเลิกคำขอได้ก่อนส่ง
- Red Plate Management มี Master Data ที่เพิ่ม/แก้ไขได้ พร้อมรายการครบกำหนดและจดทะเบียนแล้วแต่ยังไม่คืน Un-Matching ทำให้รอตรวจรับ ต้องรับคืนป้ายจริงจึงพร้อมจับคู่ใหม่
- Integrations → แหล่งข้อมูลสต๊อกภายนอก → Test Connection → Import/Sync เพิ่มรถตัวอย่างที่รอรับเข้า ทำซ้ำจะข้าม VIN เดิมโดยไม่เขียนทับข้อมูล

## Administration

Loyalty Configuration ทดลองสูตรเก่า/ใหม่ก่อนบันทึก Draft และอนุมัติ Access Control กำหนดเมนู/การกระทำ/สาขา/ข้อมูลสำคัญ Audit Log แสดงประวัติ Reports ส่งออก CSV และพิมพ์ข้อมูลจำลอง Notification Settings แก้กฎแล้วกดประเมิน ระบบป้องกันซ้ำตามความถี่และจำกัดผู้รับตามบทบาท

Reset Demo Data ล้างการเปลี่ยนแปลงในต้นแบบและสร้างวันนัดสัมพันธ์กับวันนี้ ใช้เมื่อเริ่มสาธิตรอบใหม่และไม่ต้องเก็บรายการเดิม

## OCR และ AI Assistant

OCR อยู่ใน Booking → Customer & Documents รองรับเอกสารสามประเภทพร้อมกรณีอ่านไม่ชัด บัตรหมดอายุ และข้อมูลไม่ตรง ต้องตรวจช่องความมั่นใจต่ำและยืนยันด้วยผู้ใช้ AI Assistant อยู่มุมขวาล่างทุกหน้า ตอบงานและสถานะพร้อมลิงก์ตามสิทธิ์ เมื่ออยู่หน้า Booking ถาม “สรุปการจองนี้” ได้ รายละเอียดการทดลองและจุดเชื่อม API จริงอยู่ใน `ai-demo.md` ทั้งสองระบบยังเป็น Demo ไม่เรียกบริการ AI ภายนอก

## ขอบเขตปัจจุบัน

การเชื่อมต่อทุกระบบเป็นการจำลอง PDF ใช้ Save as PDF ของหน้าต่างพิมพ์ Mapping และ ERP Import เป็นตัวอย่าง ยังไม่มี API จริงหรือระบบยืนยันตัวตนฝั่ง Server รายละเอียดความครอบคลุมและผลตรวจอยู่ใน development-baseline.md
